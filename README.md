一个零依赖的 Windows 小工具：**自定义按键替代规则**，按一个键就代替一串组合键；替代是否生效由一个「开关热键」控制。

两个目标场景：

| 场景 | 触发键（按一下） | 输出（代替按下的组合） |
| --- | --- | --- |
| A. 小键盘 `.` 代替 `Alt+Ctrl+小键盘0` | `小键盘 .` | `Alt+Ctrl+小键盘0` |
| B. 工作时不离开手位就给网易云点「喜欢」 | `F8`（可自定） | 网易云内置的「喜欢」全局快捷键（通常 `Ctrl+Alt+L`） |

## 环境要求

| 项 | 要求 |
| --- | --- |
| 系统 | Windows 10 / 11（64 位环境验证；32 位未测试） |
| Python | 3.8+，**必须带 tkinter**（官方安装包默认包含） |
| 第三方库 | **无**，纯标准库 |
| 权限 | 建议**以管理员身份运行**（见下方「权限与 UIPI」） |

## 一分钟上手

1. 双击 **`start-kuaijiejian.bat`**（或运行 `python kuaijiejian.py`）打开界面。
   启动时会弹一次 UAC 确认框，点「是」；第一次启动会在同目录生成 `config.json`，并带两条**默认关闭**的示例规则。
2. 点「新增规则」→「触发键」旁边点**录制**，按下 `小键盘 .`；
   再点「输出组合」的**录制**，按住 `Alt`+`Ctrl` 再按 `小键盘 0`；填备注后确定。
3. 勾选「仅本规则限定程序」，把目标程序名（例如 `cloudmusic.exe`）加进白名单。
   也可以点「取当前前台进程名」自动填入。
4. 回到主界面，按**开关热键（默认 `F12`）**切到「替代模式」，状态栏会变成红色提示。
5. 切到目标程序，按一下 `小键盘 .`，调试日志里会立刻出现
   `触发 小键盘 . → 左Alt+左Ctrl+小键盘 0｜注入：…`。
6. 再按一次 `F12` 回到「正常输入」，`小键盘 .` 又变回小数点。

> 启动时永远是「正常输入」，不会开机就改掉你的键位。应急想立刻停下，按**暂停热键（默认 `Pause`）**回到正常输入，或者直接退出程序。

## 权限与 UIPI（很多人会踩的坑）

Windows 的 **UIPI**（用户界面特权隔离）规定：普通权限进程的低层键盘钩子**收不到更高完整性级别（管理员）程序的按键**。

表现是：工具自己窗口里按键正常，但切到某些程序就完全收不到（日志里「心跳」计数不再增长）。

处理：

- **推荐**：用 `start-kuaijiejian.bat`（会自动请求管理员权限）；
- **不想每次弹 UAC**：用 `start-kuaijiejian-unelevated.bat`，代价是管理员程序在前台时收不到按键。

这不是本工具的缺陷，是 Windows 的安全设计（否则任何普通程序都能窃听管理员窗口的输入）。

## 安全说明

- **不联网**：程序没有任何网络请求代码，不需要账号、不上传数据。
- **不记录输入内容**：只在本地 `startup.log` 里记录按键的**键名/虚拟键码**与判定结果（用于排查），
  可在界面里关闭「记录调试日志」「把按键日志写进 startup.log」「记录原始键码」。
- **全部源码可审计**：单文件 `kuaijiejian.py`，纯标准库，可直接阅读。
- **为什么需要全局键盘钩子**：本工具的功能就是「改写按键」，必须监听全局键盘才能工作；
  注入的事件带固定签名，工具会识别并放行自己的事件，不会自触发。
- **杀软误报**：键盘钩子类工具容易被安全软件（含 Windows Defender 的启发式规则）误报。
  如被拦截，请把 `python.exe` / `pythonw.exe` 或本文件夹加入信任，并优先从源码运行。


## 界面上的每一项

- **状态栏**：当前模式、NumLock 状态、前台进程名、钩子是否运行、累计吞键/注入次数。
- **替代模式开关**
  - `切换到替代模式 / 回到正常输入`：手动切换。
  - **开关热键**（默认 `F12`）：点击后可重新录制。它是**单个按键**，不是组合键。
    **一次按压只切换一次**：按下时只是"武装"，**松开时才切换模式**；
    按住期间系统发来的所有重复按下（无论带不带长按标记）都被忽略。
    所以长按多久都只会切换一次，且不依赖系统的长按重复标记。
  - **兼容"按下事件丢失"**：如果新启动的进程只收到长按连发（典型场景：关掉工具时手指还按着热键），
    工具会把连发当作这次按住的起点，因此**松开时仍然恰好切换一次**，不会出现"有反应但模式不变"。
  - **暂停热键**（默认 `Pause`）：按下立即回到正常输入（应急用，按下就生效，不受上面规则影响）。
  - `启用替代引擎`：总开关，关掉后所有规则都不生效（但界面还能正常改配置）。
  - 模式**只在本次运行内有效**：默认下次启动总是「正常输入」。
    想让它记住上次的模式，勾选选项区里的「启动时恢复上次的模式」。
- **替代规则表**：双击某行即可编辑。列含义：
  - `触发键`：按一下就会触发规则的那一个键。**按下武装、松开才注入**——
    按住不放只算一次（长按的系统连发会被忽略），和开关热键同一套机制。
  - `输出组合`：最多 4 个键，按录制顺序注入。
  - `生效范围`：见下面「生效范围」一节，**这一列决定按了有没有反应**。
  - 规则按顺序上移/下移；同一触发键有多条规则时，**勾了「仅本规则限定程序」的规则优先匹配**。
  - 右侧有个 `选中规则改为所有程序生效`：一键把选中的规则改成「不管前台是什么程序都替换」。
- **生效范围**（最容易踩坑的地方）
  - 规则编辑器里有三个单选：
    1. `所有程序都生效`：任何程序前台时都替换（对应 `apply_to_all_apps=true`）。
    2. `只在白名单里的程序生效（跟随上方全局设置）`：只有白名单程序在前台时才替换。
    3. `只在白名单里的程序生效，且本规则单独限定`：同上，但允许你为同一个触发键准备多条规则，
       分别绑定不同程序，并让「限定程序」的规则优先匹配。
       （例：小键盘 `.` 在网易云里替代成 `Alt+Ctrl+小键盘0`，在记事本里替代成别的东西。）
  - `所有程序都生效` 复选框：全局开关，容易误伤输入，默认关闭。
  - `程序白名单`：进程名（`cloudmusic.exe`、`notepad.exe` 这种），支持填写多个。
  - `取当前前台进程名`：点一下 → 工具先**把自己最小化**，给你 **3 秒**切到目标程序
    （例如网易云）→ 时间到自动取回那个程序的进程名并填进输入框，再点「添加」即可。
    为什么要等 3 秒：点按钮的瞬间前台窗口是工具自己，直接取只会拿到 `pythonw.exe`；
    若取到的确实是 python/pythonw，工具会弹窗提醒你重新来一次。
  - 白名单为空、且没勾「所有程序」时，任何规则都不会生效——这是防止误伤的安全默认。
- **选项**
  - `NumLock 关闭时按小键盘语义匹配`：NumLock 关着的时候，小键盘 `.` 实际发出的是 `Delete`。
    勾上（默认）时，`小键盘 .` 规则依然会被命中；不勾则按真实键（`Delete`）匹配。
  - `记录调试日志`：关掉可减少界面开销。
  - `记录所有按键（含没命中的，排查用，很啰嗦）`：默认关闭。没命中规则的普通按键不写日志，
    否则正常打字会把日志刷满；但**「按了没生效」的原因一定会写日志**（例如「前台是 notepad.exe，不在白名单里」），
    所以排查时不用打开这个开关。
  - `按键按住时长(ms)`：留 0 即可；个别程序不认「零间隔」的组合键时，可调到 20–30。
  - `热键去抖(ms，长按只算一次)`：默认 300，用于判定"长按重复按下"的容差；
    工具本身靠"松开才切换"这个事件配对来保证一次按压只切换一次，所以这个数值一般不用改。
  - `启动时恢复上次的模式`：默认关闭（启动总是「正常输入」），勾上则记住上次退出时的模式。
- **调试日志**：最近 200 条，能看到每一次「触发 / 透传 / 模式切换」，是排查问题最快的地方。

## 场景 B：给网易云音乐设置「喜欢」

1. 打开网易云音乐 → 右上角齿轮「设置」→ 左侧「快捷键」。
2. 勾选**启用全局快捷键**。网易云的全局快捷键要求 `Ctrl / Alt / Shift` 之一 + 一个字母
   （「喜欢」默认通常是 `Ctrl+Alt+L`，不同版本可能不同，**以你机器上显示的为准**）。
3. 记下「喜欢」这一项当前的组合键。
4. 回到本工具 →「新增规则」：
   - 触发键：录一个你顺手的**单键**（例如 `F8`）；建议避开 `Delete`、`F5`、字母数字键这类高频键。
   - 输出组合：按第 3 步看到的键位**实际录一遍**（例如按住 `Ctrl`+`Alt` 再按 `L`）。
   - 勾选「仅本规则限定程序」→ 确定。
5. 把 `cloudmusic.exe` 加进白名单（点「取当前前台进程名」时先让网易云窗口是当前窗口最省事）。
6. 按开关热键进入替代模式，回到网易云按一下 `F8`，当前歌曲就会被标记为喜欢。

> 如果不想让替代模式开着，也可以把开关热键切成替代模式常驻：替代模式下本工具**只对白名单里的程序**动手，其它程序完全不受影响。
>
> 网易云的「喜欢」快捷键如果**没有**开启全局快捷键，那么注入的组合键只有在网易云窗口是前台时才有效（这是网易云的限制，不是本工具的）。
>
> 参考教程：[网易云音乐如何设置全局快捷键](https://soft.3dmgame.com/gl/7497.html)

| 开关热键（正常输入 ↔ 替代模式） | `F12` | 单击可改；浏览器/F12 开发者工具会同时收到，介意的话换成 `Pause` 之类 |

### 排查用快捷键：`--diag` 与 `--watch` 的区别

| | `--diag` / `diagnose-kuaijiejian.bat` | `--watch` |
| --- | --- | --- |
| 行为 | 装钩子，给你 15 秒按键，然后给结论 **并退出** | 装钩子后一直运行，每条按键判定实时打印，Ctrl+C 退出 |
| 适合 | 一次性地判断「钩子到底收不收得到键」 | 一边用一边盯，看某个键到底有没有被收到 |
| 注意 | 它自己装一套钩子；**跑诊断前请先退出正式工具**，两者同时开会互相抢按键 | 同上 |

界面里也可以点「自检：钩子有没有在收键？」做同样的 15 秒观察。

### 拷到别的电脑直接跑（便携版）

```bat
python build_portable.py              :: 生成 portable\（含随包 Python，约 45 MB）
python build_portable.py --no-python  :: 只打包程序，目标电脑需自带 Python 3.8+
```

把整个 `portable\` 文件夹拷到目标电脑（U 盘 / 网盘均可），双击里面的
`start-kuaijiejian.bat` 即可，**目标电脑不需要装 Python**（因为带了 `python\` 子目录）。

- 启动脚本会先找 `portable\python\pythonw.exe`，找不到才回退系统 PATH 里的 Python，
  并设置 `PYTHONHOME` 让随包解释器只用自己的库和 tcl/tk；
- 目录里的 `运行说明.txt` 是给目标电脑看的（怎么启动、默认键位、出问题怎么办）；
- `config.json` 会一起带过去，规则原样保留；
- 想减小体积：删掉 `portable\python\` 就是"仅程序"版（约 150 KB），但目标电脑需自装 Python。

### 按了没反应？按这个顺序排查

1. **界面里点「自检：钩子有没有在收键？」**（右下角选项区）。
   它会让你在 15 秒内按几下键，然后告诉你：钩子有没有收到你的按键、每个按键为什么生效/没生效。
2. **双击 `diagnose-kuaijiejian.bat`**：等价功能，但在命令行窗口里逐行输出，方便把结果发出来。
   **跑之前请先退出正式工具**，否则两套钩子会互相抢按键。
   注意：诊断用的是和界面**完全相同**的引擎与配置，所以诊断能触发、界面不能触发，
   差别通常在「正式工具当时到底有没有在运行 / 钩子还在不在」——这时看第 3 步。
3. **看 `startup.log`**：里面有每次启动是否装上了钩子、钩子中途有没有掉线、退出时间、
   以及（打开按键日志后）每条按键的判定。对照时间点就能知道当时工具是否活着、有没有收到键。
4. **双击 `start-kuaijiejian-console.bat`**：带控制台跑正式工具，有问题时能直接在窗口里看到输出。
5. 如果自检结论是「钩子一个按键都没收到」，那就是按键没能到达本工具：安全软件/键盘驱动拦截、
   已有其它按键工具（AutoHotkey、键盘厂商驱动）抢占，或程序不在当前用户桌面会话。
   处理：加入杀软白名单 → 彻底退出（任务管理器确认没有 `pythonw.exe`）→ 重新启动 → 再自检。

## 工作原理与安全措施

- 用 `WH_KEYBOARD_LL` 底层键盘钩子监听按键，在独立线程 + 消息循环里运行；
  命中规则时直接吞掉触发键并同步调用 `SendInput` 注入组合键
  （同步注入是为了保证注入事件与物理 KEYUP 的先后顺序正确）。
- **防死循环**：所有注入事件都带固定签名 `dwExtraInfo`，钩子识别到签名或 `LLKHF_INJECTED`
  就直接放行，绝不参与匹配。
- **防卡键**：只吞「首次 KEYDOWN」，`KEYUP` 永远透传给系统；长按自动重复不会反复触发。
- **注入前清理干扰**：如果触发时你还按着别的修饰键（例如 `Shift`），会先临时抬起，
  注入完再按回你原来的状态。
- **异常降级**：钩子回调里的任何异常都会被捕获并放行该按键，注入失败也只是记日志，
  不会让键盘卡住。
- **单实例**：重复启动只会提示「已经在运行」，不会装两套钩子。
- **不写系统目录、不改注册表、不自动设开机自启**。想开机启动，自己给
  `start-kuaijiejian.bat` 建一个快捷方式放进
  `%APPDATA%\Microsoft\Windows\Start Menu\Programs\Startup` 即可。

## 常见问题

| 现象 | 原因与处理 |
| --- | --- |
| 双击 `start-kuaijiejian.bat` 秒退、看不到界面 | 先看同目录的 **`startup.log`**，里面会写明原因。常见情况：没装 Python / 没勾选 Add Python to PATH（此时 bat 会停住并给出提示）；Python 缺少 tkinter（重新用官方安装包安装并勾选 tcl/tk）；启动时抛异常（日志里会有完整 traceback，直接发我）。 |
| 双击后什么都没发生，进程也看不到 | 大概是已经在运行了（本工具只允许一个实例），看任务管理器有没有 `pythonw.exe`；或先删掉 `startup.log` 再双击一次看日志。 |
| 状态栏「钩子：未运行」 | 被安全软件拦了，或进程被挂起。工具每 3 秒自动重装一次；仍不行就重启工具并检查杀软白名单。 |
| **按开关热键 / 触发键完全没反应，日志也没记录** | 先做自检（界面「自检：钩子有没有在收键？」或双击 `diagnose-kuaijiejian.bat`）。结论若是「钩子一个按键都没收到」：安全软件/键盘驱动拦截、别的按键工具（AutoHotkey、键盘厂商驱动）抢占，或程序不在当前桌面会话。处理：加白名单 → 彻底退出（任务管理器确认无 `pythonw.exe`）→ 重开 → 再自检。 |
| 换了键盘、或按了 `Fn` 之后热键失效 | 部分键盘的 `Fn` 锁会把 `F12` 变成媒体键（发的是别的键码，钩子收不到 `F12`）。重新录制开关热键，或换成 `Pause`。 |
| 日志显示「触发…｜注入…」但目标程序没反应 | 目标程序以管理员身份运行（如任务管理器），注入被系统 UIPI 拦了。**以管理员身份**重启本工具即可。 |
| 日志里连「触发」都没有 | 没进替代模式、规则没启用，或生效范围不匹配。现在日志会直接写明原因，例如 `透传 小键盘 +｜不生效原因：该触发键的规则只对白名单程序生效，前台是 notepad.exe`。照着改「生效范围」即可。 |
| 在网易云里能用，切到别的程序就不行 | 这条规则的生效范围是「只在白名单里的程序生效」，白名单里只有 `cloudmusic.exe`。想让它在哪儿都生效：选中该规则 → 点 `选中规则改为所有程序生效`，或双击编辑选「所有程序都生效」。 |
| 按 `小键盘 .` 没反应 | NumLock 关着时它发的是 `Delete`。默认已做归一化；若你把「NumLock 关闭时按小键盘语义匹配」关了，就按 `Delete` 触发。 |
| 长按开关热键，模式来回跳 | 已修复：开关热键改成「按下武装、**松开才切换一次**」，按住期间的重复按下全部忽略。连续点按仍然每按一次切换一次。 |
| 长按触发键，组合键被注入好几次 | 已修复：规则触发键同样是「按下武装、**松开才注入一次**」。日志里会写 `长按 小键盘 .：自动重复已忽略（松开才触发一次）`；正常点按不受影响。 |
| 显示已收到按键但模式不变 | 已修复：以前"按下"事件在程序启动/退出交替时可能丢失，只剩长按连发，导致这次按压不生效。现在连发会被当作按住的起点，松开照样切换一次。日志里会写 `检测到 F12 正处于长按（按下事件丢失），松开时切换模式`。 |
| 启动后模式不是上次的模式 | 这是默认的安全行为（启动总是「正常输入」）。想要记住，勾选「启动时恢复上次的模式」。 |
| `F12` 触发时浏览器也打开了开发者工具 | `F12` 本身还是会被系统/浏览器处理。把开关热键换成 `Pause` 或别的冷门键。 |
| 某些游戏里没用 | 用 RawInput / 反作弊驱动直接读键的游戏会绕过本工具，属于限制。 |
| 想直接改配置文件 | 可以，改完在界面上点「重新加载配置」；JSON 写错会自动备份并回默认。 |

## 已知限制

- 仅支持 Windows 10/11（64 位环境验证）。
- 低层键盘钩子受 UIPI 限制，需管理员权限才能收到管理员程序的按键。
- 触发键目前**只能是单个按键**；输出组合最多 4 个键。
- 「连按多个组合键」（例如先 `Ctrl+Alt+L` 再 `Right`）暂不支持。
- 不区分左右修饰键的语义：规则里按住哪个 `Ctrl` 就触发哪个（左右都能触发同一条规则）。
- 注入对个别游戏/带反作弊的软件无效。
- 未签名可执行文件可能被 SmartScreen 或安全软件提示。
